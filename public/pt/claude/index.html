Como funciona o link do Claude

O Claude, da Anthropic, lê o prompt de um parâmetro da URL. O link que esta página monta tem a forma https://claude.ai/new?q=SEU+PROMPT, com o prompt codificado para URL.

Abre um novo chat no claude.ai com o prompt. A Anthropic já mudou esse comportamento antes: se a caixa estiver vazia, use Copiar prompt.

Exige uma conta Claude.

Use o Claude pela barra de endereço

Adicione um buscador personalizado ao navegador com a URL https://searchgptforme.com/pt/claude/?go=1&q=%s e um atalho como claude. Digitar claude como cozinhar arroz então manda a pergunta direto para o Claude. No Chrome isso fica em Configurações, Mecanismo de pesquisa, Gerenciar mecanismos de pesquisa e pesquisa no site.

Compartilhe um prompt do Claude

Em vez de dizer "pergunta ao Claude", envie o link: ele abre o Claude com o seu prompt exato. Um link para esta página, por exemplo https://searchgptforme.com/pt/claude/?q=explique+computação+quântica, deixa a pessoa revisar o prompt antes.
