Como funciona o link do Grok

O Grok, da xAI, lê o prompt de um parâmetro da URL. O link que esta página monta tem a forma https://grok.com/?q=SEU+PROMPT, com o prompt codificado para URL.

Abre o grok.com com o prompt na caixa de entrada.

Exige uma conta X ou Grok.

Use o Grok pela barra de endereço

Adicione um buscador personalizado ao navegador com a URL https://searchgptforme.com/pt/grok/?go=1&q=%s e um atalho como grok. Digitar grok como cozinhar arroz então manda a pergunta direto para o Grok. No Chrome isso fica em Configurações, Mecanismo de pesquisa, Gerenciar mecanismos de pesquisa e pesquisa no site.

Compartilhe um prompt do Grok

Em vez de dizer "pergunta ao Grok", envie o link: ele abre o Grok com o seu prompt exato. Um link para esta página, por exemplo https://searchgptforme.com/pt/grok/?q=explique+computação+quântica, deixa a pessoa revisar o prompt antes.

Envie o texto selecionado para o Grok

Arraste o botão abaixo para a barra de favoritos. Selecione um texto em qualquer página e clique nele: o Grok abre com esse texto como prompt.
