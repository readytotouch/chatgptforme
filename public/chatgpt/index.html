How the ChatGPT link works

ChatGPT by OpenAI reads the prompt from a URL parameter. The link this page builds has the form https://chatgpt.com/?q=YOUR+PROMPT, with the prompt URL-encoded.

Opens chatgpt.com with the prompt in the input. Since mid-2025 OpenAI no longer auto-submits prompts that arrive from another site, so press Enter once.

Use ChatGPT from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/chatgpt/?go=1&q=%s and a shortcut such as chatgpt. Typing chatgpt how to boil rice then sends the question straight to ChatGPT. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a ChatGPT prompt

Instead of telling someone "just ask ChatGPT", send them the link: it opens ChatGPT with your exact prompt. A link to this page, for example https://searchgptforme.com/chatgpt/?q=explain+quantum+computing, lets them review the prompt first.
