Cómo funciona el enlace de Grok

Grok, de xAI, lee el prompt desde un parámetro de la URL. El enlace que construye esta página tiene la forma https://grok.com/?q=TU+PROMPT, con el prompt codificado para URL.

Abre grok.com con el prompt en el cuadro de entrada.

Requiere una cuenta de X o de Grok.

Usa Grok desde la barra de direcciones

Añade un buscador personalizado a tu navegador con la URL https://searchgptforme.com/es/grok/?go=1&q=%s y un atajo como grok. Escribir grok cómo cocinar arroz envía entonces la pregunta directamente a Grok. En Chrome está en Configuración, Buscador, Gestionar buscadores y búsqueda en sitios.

Comparte un prompt de Grok

En lugar de decir «pregúntale a Grok», envía el enlace: abre Grok con tu prompt exacto. Un enlace a esta página, por ejemplo https://searchgptforme.com/es/grok/?q=explica+la+computación+cuántica, permite revisar el prompt antes.

Envía el texto seleccionado a Grok

Arrastra el botón de abajo a tu barra de marcadores. Selecciona texto en cualquier página y haz clic: Grok se abre con ese texto como prompt.
