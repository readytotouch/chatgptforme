How the Copilot link works

Copilot by Microsoft reads the prompt from a URL parameter. The link this page builds has the form https://copilot.microsoft.com/?q=YOUR+PROMPT, with the prompt URL-encoded.

Since November 2025 Copilot shows the query as a heading instead of filling the chat box. One more click starts the conversation.

Works without an account, sign in for longer chats.

Use Copilot from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/copilot/?go=1&q=%s and a shortcut such as copilot. Typing copilot how to boil rice then sends the question straight to Copilot. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a Copilot prompt

Instead of telling someone "just ask Copilot", send them the link: it opens Copilot with your exact prompt. A link to this page, for example https://searchgptforme.com/copilot/?q=explain+quantum+computing, lets them review the prompt first.
