How the Claude link works

Claude by Anthropic reads the prompt from a URL parameter. The link this page builds has the form https://claude.ai/new?q=YOUR+PROMPT, with the prompt URL-encoded.

Opens a new chat on claude.ai with the prompt. Anthropic has changed this behaviour before, so if the box is empty use Copy prompt.

Requires a Claude account.

Use Claude from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/claude/?go=1&q=%s and a shortcut such as claude. Typing claude how to boil rice then sends the question straight to Claude. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a Claude prompt

Instead of telling someone "just ask Claude", send them the link: it opens Claude with your exact prompt. A link to this page, for example https://searchgptforme.com/claude/?q=explain+quantum+computing, lets them review the prompt first.
