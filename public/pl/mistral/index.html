Jak działa link do Le Chat

Le Chat nie ma udokumentowanego parametru URL dla promptu. Skopiuj prompt i wklej go do czatu.

Inni asystenci, tacy jak ChatGPT, Claude i Perplexity, przyjmują prompt w adresie URL. Dopóki Mistral AI nie doda tego samego, ta strona trzyma twój prompt o jedno kliknięcie od schowka.
