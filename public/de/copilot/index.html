Prompt-Link-Generator für Microsoft Copilot

SearchGPT For Me / Microsoft Copilot

Gib eine Frage ein und erhalte einen Link, der Copilot mit bereits eingetragenem Prompt öffnet. Teile ihn, speichere ihn als Lesezeichen oder nutze ihn aus der Adressleiste.

In Copilot öffnen Lieber alle KIs fragen

So funktioniert der Copilot-Link

Copilot von Microsoft liest den Prompt aus einem URL-Parameter. Der Link, den diese Seite baut, hat die Form https://copilot.microsoft.com/?q=DEIN+PROMPT, mit URL-kodiertem Prompt.

Seit November 2025 zeigt Copilot die Frage als Überschrift, statt das Chatfeld zu füllen. Ein weiterer Klick startet das Gespräch.

Ohne Konto nutzbar, für längere Chats anmelden.

Copilot aus der Adressleiste nutzen

Füge deinem Browser eine eigene Suchmaschine mit der URL https://searchgptforme.com/de/copilot/?go=1&q=%s und einem Kürzel wie copilot hinzu. copilot wie kocht man Reis schickt die Frage dann direkt an Copilot. In Chrome findest du das unter Einstellungen, Suchmaschine, Suchmaschinen und Website-Suche verwalten.

Einen Copilot-Prompt teilen

Statt „frag doch Copilot“ zu sagen, schick den Link: Er öffnet Copilot mit genau deinem Prompt. Ein Link auf diese Seite, zum Beispiel https://searchgptforme.com/de/copilot/?q=erkläre+Quantencomputer, lässt den Prompt vorher prüfen.

Markierten Text an Copilot senden

Zieh den Button unten in deine Lesezeichenleiste. Markiere Text auf einer beliebigen Seite und klick darauf: Copilot öffnet sich mit diesem Text als Prompt.
