How the Perplexity link works

Perplexity by Perplexity AI reads the prompt from a URL parameter. The link this page builds has the form https://www.perplexity.ai/search?q=YOUR+PROMPT, with the prompt URL-encoded.

Runs the search immediately and shows an answer with sources.

No account needed.

Use Perplexity from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/perplexity/?go=1&q=%s and a shortcut such as perplexity. Typing perplexity how to boil rice then sends the question straight to Perplexity. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a Perplexity prompt

Instead of telling someone "just ask Perplexity", send them the link: it opens Perplexity with your exact prompt. A link to this page, for example https://searchgptforme.com/perplexity/?q=explain+quantum+computing, lets them review the prompt first.
