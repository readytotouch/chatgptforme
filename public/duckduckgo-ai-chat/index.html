How the Duck.ai link works

Duck.ai by DuckDuckGo reads the prompt from a URL parameter. The link this page builds has the form https://duckduckgo.com/?ia=chat&q=YOUR+PROMPT, with the prompt URL-encoded.

Anonymous chat with GPT, Claude, Llama or Mistral models, chosen inside Duck.ai.

No account needed.

Use Duck.ai from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/duckduckgo-ai-chat/?go=1&q=%s and a shortcut such as duckduckgo-ai-chat. Typing duckduckgo-ai-chat how to boil rice then sends the question straight to Duck.ai. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a Duck.ai prompt

Instead of telling someone "just ask Duck.ai", send them the link: it opens Duck.ai with your exact prompt. A link to this page, for example https://searchgptforme.com/duckduckgo-ai-chat/?q=explain+quantum+computing, lets them review the prompt first.
