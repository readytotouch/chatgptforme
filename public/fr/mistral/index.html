Comment fonctionne le lien Le Chat

Le Chat n'a pas de paramètre d'URL documenté pour le prompt. Copiez le prompt et collez-le dans le chat.

D'autres assistants comme ChatGPT, Claude et Perplexity acceptent un prompt dans l'URL. En attendant que Mistral AI fasse de même, cette page garde votre prompt à un clic du presse-papiers.
