Comment fonctionne le lien ChatGPT

ChatGPT, de OpenAI, lit le prompt dans un paramètre d'URL. Le lien construit par cette page a la forme https://chatgpt.com/?q=VOTRE+PROMPT, avec le prompt encodé pour l'URL.

Ouvre chatgpt.com avec le prompt dans le champ de saisie. Depuis mi-2025, OpenAI n'envoie plus automatiquement les prompts venant d'un autre site : appuyez une fois sur Entrée.

Fonctionne sans compte pour l'usage de base ; connectez-vous pour toutes les fonctions.

Utilisez ChatGPT depuis la barre d'adresse

Ajoutez un moteur de recherche personnalisé à votre navigateur avec l'URL https://searchgptforme.com/fr/chatgpt/?go=1&q=%s et un raccourci comme chatgpt. Taper chatgpt comment cuire du riz envoie alors la question directement à ChatGPT. Dans Chrome, c'est dans Paramètres, Moteur de recherche, Gérer les moteurs de recherche et la recherche sur les sites.

Partagez un prompt ChatGPT

Au lieu de dire « demande à ChatGPT », envoyez le lien : il ouvre ChatGPT avec votre prompt exact. Un lien vers cette page, par exemple https://searchgptforme.com/fr/chatgpt/?q=explique+l'informatique+quantique, permet de relire le prompt d'abord.

Envoyez le texte sélectionné à ChatGPT

Glissez le bouton ci-dessous dans votre barre de favoris. Sélectionnez du texte sur n'importe quelle page et cliquez dessus : ChatGPT s'ouvre avec ce texte comme prompt.
