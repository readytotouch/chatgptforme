How the Grok link works

Grok by xAI reads the prompt from a URL parameter. The link this page builds has the form https://grok.com/?q=YOUR+PROMPT, with the prompt URL-encoded.

Opens grok.com with the prompt in the input.

Requires an X or Grok account.

Use Grok from your address bar

Add a custom search engine to your browser with the URL https://searchgptforme.com/grok/?go=1&q=%s and a shortcut such as grok. Typing grok how to boil rice then sends the question straight to Grok. In Chrome this lives under Settings, Search engine, Manage search engines and site search.

Share a Grok prompt

Instead of telling someone "just ask Grok", send them the link: it opens Grok with your exact prompt. A link to this page, for example https://searchgptforme.com/grok/?q=explain+quantum+computing, lets them review the prompt first.
