Come funziona il link di Le Chat

Le Chat non ha un parametro URL documentato per il prompt. Copia il prompt e incollalo nella chat.

Altri assistenti come ChatGPT, Claude e Perplexity accettano un prompt nell'URL. Finché Mistral AI non farà lo stesso, questa pagina tiene il tuo prompt a un clic dagli appunti.
